# Finance Portfolio Tracker

Це веб-додаток для відстеження інвестиційного портфеля, перегляду ринкових цін на активи, керування списком спостереження (watchlist) та історії транзакцій.

---

## 1. Бізнес-вимоги (Business Requirements)
Ціль проєкту — створити зручний інструмент для приватних інвесторів, що дозволяє централізовано керувати своїми фінансовими активами.

* **Керування портфелем:** Користувач повинен мати можливість бачити список своїх активів, загальну вартість портфеля, прибуток/збиток (PnL) та ROI.
* **Моніторинг ринку:** Можливість додавати активи до "списку спостереження" (Watchlist) та переглядати актуальні ціни.
* **Операційність:** Можливість фіксувати угоди купівлі/продажу, що автоматично оновлює баланс користувача та склад портфеля.
* **Безпека:** Доступ до даних лише авторизованим користувачам через персональні облікові записи.

## 2. Технічні вимоги (Technical Requirements)

* **Backend:** * Мова: C# (.NET 8/9).
    * Сервер: `System.Net.HttpListener` (Custom API server).
    * База даних: Entity Framework Core (SQL Provider).
    * Автентифікація: JWT (JSON Web Tokens).
    * Хешування: BCrypt.Net.
* **Frontend:** * Framework: React + TypeScript.
    * Керування станом: React Hooks.
    * Зв'язок: Fetch API / Axios.
* **Infrastructure:** * Система контролю версій: Git.
    * Середовище: Cross-platform (Windows/Linux).

## 3. Опис архітектури проєкту (Architecture Description)

Проєкт побудований за архітектурою **Client-Server**. Клієнт взаємодіє з сервером через HTTP-запити, отримуючи дані у форматі JSON.


**Потік обробки запиту:**
1. Клієнт надсилає запит (наприклад, `POST /api/portfolio/buy`).
2. `RequestHandler` перевіряє права доступу та маршрут.
3. Викликається відповідний `Handler`
4. `Handler` виконує бізнес-логіку та запити до БД через `DbContext`.
5. Результат повертається клієнту.

## 4. Інструкції з розгортання та використання

### Початок роботи
1. **Клонування:** `git clone 
2. **Backend:**
   * Встанови [.NET SDK](https://dotnet.microsoft.com/).
   * У папці проєкту виконайте: `dotnet restore`
   * Налаштуйте рядок підключення до БД у файлі конфігурації.
   * Запуск: `dotnet run`
3. **Frontend:**
   * Встанови [Node.js](https://nodejs.org/).
   * У папці проєкту виконайте: `npm install`
   * Запуск: `npm run dev`

### API Endpoints
* `POST /api/login` - Вхід у систему
* `POST /api/register` - Реєстрація
* `GET /api/portfolio` - Дані портфеля
* `POST /api/portfolio/buy` - Купівля активу
* `POST /api/portfolio/sell` - Продаж активу
* `GET /api/watchlist` - Список спостереження
* `POST /api/watchlist/add` - Додавання активу
* `DELETE /api/watchlist/remove` - Видалення активу
